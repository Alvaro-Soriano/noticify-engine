# noticify-engine
Motor de búsqueda que recolecta e indexa avisos aéreos, marítimos y otros comunicados emitidos por agencias oficiales.

El motor soporta:
* Consultas por palabra clave, fecha, tipo de aviso y agencia.
* Normalización de datos provenientes de distintas fuentes.
* Tratamiento de coordenadas geográficas (conversión de formatos, interpretación de radios y polígonos).

Su objetivo es unificar y facilitar el acceso a información oficial dispersa en múltiples sistemas.
